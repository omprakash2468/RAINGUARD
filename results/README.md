# Results

This folder contains selected outputs generated by the RAINGUARD prototype.

## Planned Results

- Chennai flood-risk map
- Predicted inundation map
- Sentinel-1 observed flood map
- Spatial validation results
- Flood-risk visualization
- Exposure analysis for population, roads and critical facilities

## Validation

RAINGUARD evaluates predicted flood-risk maps against Sentinel-1-derived flood observations.

Evaluation includes:

- Precision
- Recall
- F1-score
- IoU / CSI
- Spatial-tolerance analysis

The validation results should be interpreted together with the spatial matching methodology described in the main project documentation.
