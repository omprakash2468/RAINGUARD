# RAINGUARD Dashboard

This folder contains the Streamlit-based dashboard for the RAINGUARD flood-risk prediction system.

## Features

- Chennai flood-risk visualization
- Rainfall and flood-risk scenario controls
- Interactive map visualization
- Disaster replay/timeline visualization
- Model validation and benchmark information
- Civil-defense advisory bulletin
- Downloadable advisory outputs
